# ATELIER STUDIO: Αρχιτεκτονική & Εσωτερικοί Χώροι

Δημόσιος ιστότοπος portfolio (Φάση 1: design system & αρχική σελίδα).
React 19 · TypeScript · Vite · Tailwind CSS v4 · GSAP + ScrollTrigger · React Router.

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # παραγωγή στο dist/
npm run images     # επαναδημιουργία εικόνων από assets-src/photos
```

- Design system: `design-system/atelier-studio/MASTER.md` (διαβάστε το πριν από κάθε οπτική αλλαγή).
- Αρχιτεκτονική & πλάνο CMS: `docs/ARCHITECTURE.md`.
- Όλο το περιεχόμενο και οι φωτογραφίες είναι **προσωρινά** (βλ. `assets-src/photos/SOURCES.md`).
